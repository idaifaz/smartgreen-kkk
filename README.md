# SmartGreen KKK

Laman SmartGreen Kolej Komuniti Kuantan: program dan aktiviti kelestari mengikut tahun dan kategori.

- `index.html`: laman (data aktiviti dan gambar terpilih terbenam dalam fail)
- `gambar/`: gambar awam yang dipilih untuk paparan

Hanya ringkasan awam dan gambar terpilih dipaparkan. Laporan penuh tidak disiarkan.
